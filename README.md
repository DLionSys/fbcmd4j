# fbcmd4j

Sistema de administración de citas médicas desarrollado en Java.

La aplicación permite registrar doctores y pacientes, crear citas médicas y relacionar cada cita con un doctor y un paciente. También incluye autenticación de administradores y persistencia de información mediante archivos CSV.

## Instalación y configuración

### Requisitos

- Java Development Kit (JDK) 11
- IntelliJ IDEA o cualquier IDE compatible con Java
- Git

### Clonar el repositorio

```bash
git clone https://github.com/DLionSys/fbcmd4j.git
