# fbcmd4j

Sistema de administración de citas para un consultorio clínico desarrollado en Java.

## Instalación y configuración

1. Instalar Java Development Kit (JDK) 11.
2. Instalar IntelliJ IDEA.
3. Instalar y configurar Git.
4. Clonar o descargar este repositorio.
5. Abrir el proyecto en IntelliJ IDEA.
6. Configurar JDK 11 como SDK del proyecto.
7. Ejecutar la clase principal de la aplicación.

## Uso del programa

El programa permitirá administrar las citas de un consultorio clínico.

Las principales funciones serán:

- Registrar doctores.
- Registrar pacientes.
- Crear citas con fecha y hora.
- Relacionar cada cita con un doctor y un paciente.
- Controlar el acceso al sistema mediante administradores.
- Almacenar la información del sistema en archivos.
